# 合成六桥臂绘图练习

`synthetic_arms.csv` 由本仓库 `scripts/stage03c1_acceptance.py` 的正弦公式生成，含 401 个时间点（1.3–1.7 s）和 6 个重复表头通道。数据完全合成，可公开演示，不含真实科研采样、故障证据或授权凭据。

## 无 AI 的第一轮练习

按[README](../../README.md#下载与安装)启动工作台：

1. 左侧上传本目录 CSV，点击“导入上传文件”。
2. 检查 6 个通道保持独立，重复表头不应合并。
3. 按原始列序，演示约定为 A上、A下、B上、B下、C上、C下，单位 kV。通过属性与物理映射界面确认并命名，确认来源填写“公开合成示例说明”。该约定不适用于其他文件。
4. 添加三幅子图，每相两条曲线；时间范围设为 1.3–1.7 s，用颜色和实线/虚线区分上下桥臂。
5. 保存为新工程 `Synthetic_practice`，导出 PDF 与 PNG；重启并打开工程核对。

成功判据：6 条曲线保持独立，三幅子图各两条；导出文件可打开、标签可读；重开工程后单位、样式和曲线一致。合成示例不用于评价真实电气系统故障性能。

## 可选 AI 练习

按 [MCP 指南](../../docs/codex_mcp.md)或[手动协作指南](../../docs/manual_dialogue_workflow.md)准备对应方式，然后尝试：

> 将第一幅子图的第二条曲线改成红色虚线，其他曲线和时间范围保持不变。

检查指定属性变化、其余属性保留，并测试撤销。需要保存时另行明确要求或点击 GUI 保存。

公开练习无需运行历史验收脚本。脚本会创建验收目录、工程和记录，面向开发验证；“脚本 JSON 验收”与真实 ChatGPT/Codex 对话验收应分别标注。不要将 reports 中私有案例和个人工程混入公开分享。
