# 可公开使用的合成六桥臂演示

`synthetic_arms.csv` 完全由 `scripts/stage03c1_acceptance.py` 的正弦公式生成，含401个时间点（1.3–1.7s）和6个重复表头通道。没有科研源数据、授权凭据或真实故障波形。本轮未发布到外部网站。

演示约定顺序：A上、A下、B上、B下、C上、C下；单位kV仅为演示定义。导入后在“确认物理映射”选择 six_arms 并确认来源、单位，选择全部通道。可先运行验收脚本生成已配置工程，直接打开合成 Browser_base。

后续使用工作台默认的“ChatGPT 手动协作”，按 test_prompts 中12条任务人工测试。脚本生成的请求、返回及图片必须标注“脚本 JSON 验收”；只有用户实际在 ChatGPT 中取得的返回才能标记 user_chatgpt。

请只使用本目录的合成CSV及合成演示说明作为公开素材，reports 下真实PSCAD案例、工程和请求不属于公开演示素材。
