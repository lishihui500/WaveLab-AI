# 六桥臂绘图教程

用随附的 [`synthetic_arms.csv`](synthetic_arms.csv) 练习三幅子图、曲线样式和工程保存。先按[首页](../../README.md#快速开始)启动工作台。

## 示例数据

CSV 包含 401 个时间点，时间范围为 1.3–1.7 s。六条通道按下表定义，单位为 kV：

| 信号列序号 | 名称 | 建议子图 |
|---|---|---|
| 1 | A 相上桥臂 | A 相 |
| 2 | A 相下桥臂 | A 相 |
| 3 | B 相上桥臂 | B 相 |
| 4 | B 相下桥臂 | B 相 |
| 5 | C 相上桥臂 | C 相 |
| 6 | C 相下桥臂 | C 相 |

数据由 `scripts/stage03c1_acceptance.py` 中的正弦公式生成，用于教学和软件操作演示。列序号从时间列之后的第一条信号计起。

## 1. 导入并命名

在左侧上传 CSV，点击“导入上传文件”。展开“通道属性”，按上表逐行填写图例名称，将物理量设为电压、源单位设为 kV，点击表内保存按钮。

## 2. 分为三幅子图

初始子图用于 A 相，勾选前两条通道并应用。再添加两幅子图，分别选择第 3、4 列和第 5、6 列。将子图标题设置为 A 相、B 相、C 相，时间范围设置为 `1.3, 1.7` s。

## 3. 调整样式

每幅子图用实线表示上桥臂、虚线表示下桥臂。将图例放在顶部，选择单栏或双栏画布尺寸，调整字号和线宽。可在“局部放大图”中新增 1.49–1.51 s 的放大窗口。

## 4. 导出与保存

选择 PDF 和 PNG，点击“导出当前视图”并下载。将工程命名为 `Synthetic_practice`，点击“保存工程”；下次从左侧工程列表打开继续编辑。

## 5. 试试自然语言编辑

按 [Codex 指南](../../docs/codex_mcp.md)连接后，点击“设为 Codex 编辑目标”，输入：

> 将第一幅子图的第二条曲线改成红色虚线，其他曲线保持不变。

还可以要求：

> 将第三幅子图移到第一幅，并把所有图例放在顶部。

使用“撤销”可返回上一步。更多操作见[使用指南](../../docs/getting_started.md)。
