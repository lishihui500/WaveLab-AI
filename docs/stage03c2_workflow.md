# WaveLab AI 3C.2 使用说明

## 连贯的编辑关系

- 左栏选择数据集与目标子图，右栏自动切换同一子图；右栏切换也会同步左栏。曲线选择只显示当前子图中的曲线。
- 当前曲线旁的“编辑当前通道名称与单位”修改该通道在整个工程中的显示元数据；左栏保留多通道批量编辑入口。原始列名、通道 ID、源列序和数值不变。
- “图例使用通道名称”可作用于当前曲线、当前子图或全图。先选择范围，再确认替换；支持一次复制与自动跟随。自动跟随使用原通道字符串，两种语言保持同名。编辑任一语言图例会解除跟随，另一语言保留当时的有效名称。自定义图例不会随通道重命名而改变。
- “图例附加通道单位（全图）”决定图例是否追加 `(kV)` 等单位；默认沿用旧版行为。关闭后可让图例仅显示名称，把公共单位集中放在 Y 轴。
- Y 轴边上检查已确认单位、未知单位、轴文字与通道单位不一致的情况；同轴多个不同已知单位仍由 FigureSpec 严格拒绝。文字单位检查支持括号或斜杠末尾标注，只做字符串核对。未知单位不从轴标题反推，也不认定为已知冲突。
- “用已确认单位生成 Y 轴标题”：填写物理量中英文名称，检查已知单位后确认替换两套标题。已有标题不自动覆盖。单位未知或部分未知时禁用辅助生成。
- X 轴始终来自 Domain 的秒值；切换 s/ms 自动换算显示范围。点击“X 轴标题跟随时间单位”清除自定义标题，交给渲染器按当前语言和时间单位动态生成。自定义轴标题继续独立保存。

## 等待 ChatGPT 期间继续编辑

原三步“生成请求 → 粘贴 JSON 并验证 → 核对并确认”保留。输入文字和 JSON 在本会话 rerun、模式切换中保留。

修改 Y 轴标题后导入原图例方案：界面显示“检测到工程已发生修改，但 AI 方案与当前配置无冲突，已重新校验。”可查看手动字段、AI 字段、当前到候选的差异及试绘图。确认前有效图形保持不变。

确认按钮点击时若当前图形再次变化，会重新检查并更新候选图，本次点击只返回新预览；核对后再次确认。若存在冲突会显示具体字段或依赖原因。应用后的撤销只撤销该次 AI 提交，保留此前手动修改。一个请求应用或取消后关闭。

## 合并规则

保留不可变 Base、Current 和在 Base 上执行白名单 Plan 得到的 Proposed。先验证原 request_id/revision/fingerprint、本地 Workbench 和工程实例，再检查变化：

| 情况 | 行为 |
|---|---|
| 版本与配置均未变化 | 正常完整校验及试绘 |
| 互不重叠的叶字段 | 在 Current 重执行原 Plan、校验并试绘 |
| 同字段最终值相同 | 允许幂等修改 |
| 同字段不同值、父字段替换覆盖子字段 | 报告字段冲突 |
| 显式写入 Base 旧值将覆盖手动修改 | 拒绝，不把无差异写入当作无操作 |
| 数据集/通道元数据、单位、物理映射、子图或曲线身份/顺序变化 | 保守拒绝 |
| 工程已变化且 Plan 含创建/删除/移动曲线或子图、Undo/Redo | 保守拒绝 |
| 双方涉及时间轴、事件、X 范围 | 作为坐标依赖保守拒绝 |
| 等待期间发生 Undo/Redo | 历史依赖变化，拒绝 |
| 重新打开或切换工程、篡改返回绑定、复用已关闭请求 | 拒绝 |

重校验保留样本哈希、原白名单、引用、映射、单位约束和本地试绘；确认仍由原执行器重新构建并检查候选一致性。API 和 Mock 模式保留原版本策略。

## 请求上下文

自动模式只对完整匹配、语义明确的名称同步句式缩小操作与通道范围；出现额外意图或不能确定范围时发送完整脱敏元数据。指定“当前”的同步需有有效当前子图，否则退回完整上下文。没有把一般自然语言通过单个关键词强行分成一种操作。

可主动选择“当前图形”或“全部数据集元数据”。当前图形范围不含未绘制通道；请求内说明范围外目标需要澄清并补充上下文。跨数据集、添加通道和复杂布局默认保留完整元数据与16种操作。协议从实际 Pydantic/执行器字段生成，只发送一份响应 schema；相关参数仍保留类型和范围约束。协议放在紧凑 JSON 行，通道和图形部分保留可读缩进。

不发送采样数组、文件路径、源哈希、工程名或凭据。标签/自然语言可能含用户自己输入的研究内容，复制前检查。

## 兼容与限制

在 FigureSpec 0.3 中增加带默认值的 `SeriesSpec.legend_source="custom"`、`LegendSpec.show_units=true`，新程序可读取没有这两字段的旧 0.2/0.3 工程。已有双语图例与旧渲染行为保留；跟随关系保存后继续生效。新工程回退到旧版程序读取不保证兼容。没有修改数据格式或绘图引擎架构。

轴标题仍是自由文字，无法验证任意自然语言里隐含的单位或自动解释所有数学排版；推荐括号或末尾斜杠标注。没有 V/kV 数值换算、单位猜测或自动翻译。新旧测试中的脚本/Mock 只证明本地行为，真实 ChatGPT 返回的理解质量需用户人工验证。
