# 绘图信息布局

## 确认与自动命名

1. 导入后选择当前子图与曲线；新多子图默认共享 X 轴。
2. 右侧显示自动轴名。未确认物理量或单位时，轴上显示“待确认物理量/单位”，同时列出需确认通道。
3. 打开“确认物理量与单位，自动命名 Y 轴”，填写中文物理量、英文物理量与单位；勾选确认后提交。作用范围为当前子图全部可见通道，并更新这些通道在其他子图的引用。
4. 确认后 Y 轴按坐标轴语言生成，例如“电容电压 (kV)”或“Capacitor voltage (kV)”。双语必须由用户明确填写，不自动翻译或从 Ucap 等名字猜测。
5. 同轴存在不同已确认物理量时提示分图；不同已知单位仍由原校验规则拒绝。

`Channel.quantity` 是新的可选、不可变确认记录，含 zh/en、unit 和 confirmation_source。相别/桥臂 physical_role 继续独立保存。旧工程缺少 quantity 时视为尚未确认，不从旧标题反推。

## 单位与标签

- 图例默认只显示名称。渲染时先移除常见末尾单位，再按 legend.show_units 决定是否追加一次确认单位；legend.axis_show_units 控制轴上单位。原 label/label_i18n 完整保留。
- Y 轴默认读取确认记录与当前有效单位。panel.ylabel_mode="custom" 时使用独立的 ylabel_i18n/ylabel，自定义文字不确认单位，冲突时提示。修改通道单位会使旧确认失效；需要重新确认物理量和单位。改变轴文字不改变物理单位或样本数值。
- X 轴使用明确约定的 Domain 秒值，自动显示“时间 (s)”或“Time (ms)”等。共享时仅底部子图显示时间标题及刻度数字。
- s/ms 切换是用户显式的时间显示换算，同时换算显示范围；不改变原始 Domain 秒值和信号值。没有 V/kV 等信号数值换算。
- X 双语历史字段继续保留，X 默认按 Domain 时间生成；Y 双语文字可在 custom 模式使用。

## 局部更新与论文版式

确认物理量、编辑单位、通道名或图例均走 Workbench 的原子配置提交，可撤销/恢复；不调用解析导入或 AI 规划。双语图例、颜色、线型、线宽、可见性、范围及页宽不因确认动作重置。

默认 IEEE 双栏7.16 in，可选单栏3.5 in；无网格、原科研配色与线型保留。PDF/PNG/SVG与工作台使用同一套确认式轴命名。保存工程后确认记录与双语字段一起恢复。
