# WaveLab AI 学术海报设计规范

> 本文是视觉与内容组织建议，不得覆盖 `课程提交规范.md` 中的课程硬性要求，也不得覆盖根目录 `AGENTS.md` 中的数据保护和工作模式约定。

## 设计目标
制作可直接展示给教师和同学的一页学术海报。观众应能迅速理解：研究问题是什么、AI 做了哪些可验证的绘图操作、绘图前后发生了什么变化、已有结果支撑什么结论。

## 核心叙事
以“真实原始图 Before → 真实自然语言指令 → Codex/LLM 与 MCP 操作 → 真实输出图 After”为主视觉。图形变化应与指令编号对应，例如子图重组、通道及单位规范化、事件标注、局部放大、Trip 数字轨道。代表性指令可摘录，但需表明是节选；不得把设计示意伪装为真实 GUI。

## 内容安排（A1 竖版）
- 顶部：项目名称、作者及一句话价值主张。
- 上部：研究问题和简洁技术架构。
- 中部：最大面积展示 Before / Instruction / After，以及放大后的关键变化。
- 下部：真实工作台界面、关键实验结果与定量验证。
- 底部：主要贡献与少量必要引用资料。

比例为设计参考而非必须的硬约束。优先保证文字及波形刻度可读、空白适当、视觉重心明确。

## 真实材料与科学边界
- 首选“汇报绘图案例”的真实工程、截图、输出及执行记录，不能伪造操作记录或曲线。
- 波形变化不等于 AI 已实现自动故障识别；不要宣传没有验证的能力或效率提升。
- 故障相别、测点映射有疑问时，核实后再写结论；不能核实则使用中性案例名称。
- 去除“待用户确认”“审阅稿”等内部语言；缺失的作者学号等信息应在交付说明中提示，不得臆造。

## 视觉与交付自检
- 白/浅色背景，深蓝或深青为主，适度强调色；统一字体、栅格、图例与标注层级。
- 原图与结果图具备前后对比，图文形成对应关系，不能只堆放一张六子图。
- 海报 PDF 保持矢量优先，PNG 分辨率满足课程要求；真实渲染并检查字体、错位、遮挡、裁切、图例和细节可读性。
- 可用 Matplotlib、SVG/draw.io、PowerPoint 等组合制作，源文件尽量可编辑。
