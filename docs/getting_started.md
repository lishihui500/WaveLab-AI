# 绘图与使用指南

[返回首页](../README.md) · [六桥臂教程](../examples/stage03c1_demo/README.md) · [Codex 接入](codex_mcp.md)

## 启动工作台

按[快速开始](../README.md#快速开始)安装后，在项目目录执行启动命令。Windows 也可运行 `start_workbench.ps1`。

浏览器打开 [本地工作台](http://127.0.0.1:8501)。页面左侧管理数据和工程，中间预览画布并导出图形，右侧设置子图和曲线。

## 导入数据

在“导入 TXT / CSV”上传文件并点击“导入上传文件”，或在“粘贴 PSCAD 数据”中粘贴含表头的文本。

数据使用逗号分隔，首行是表头，首列 `Domain` 为时间（秒），后续列为各通道数值：

```csv
Domain,current,current
0.000,1.0,2.0
0.001,1.2,1.8
0.002,1.1,1.9
```

时间按递增顺序排列。重复列名会显示为不同通道，可分别命名。PSCAD、MATLAB/Simulink、PLECS 和仪器数据均可整理为上述格式后导入。

## 选择通道与设置单位

1. 在左侧选择数据集和目标子图。
2. 勾选要显示的通道，点击应用按钮。
3. 在通道属性中填写展示名称、物理量和源单位；按数据说明确认相序或桥臂映射。
4. 在绘图设置中选择坐标轴显示单位，例如把 V 显示为 kV。

源单位描述文件中的数值，显示单位决定坐标刻度。相同通道在不同子图中共用源属性。详细设置见[物理量与单位](quantity_presets.md)。

## 组织子图和曲线

在右侧“子图”选择要编辑的子图，点击“添加子图”增加绘图区。通过排序卡片调整上下顺序。

在“曲线与图例样式”选择曲线，设置颜色、线型、线宽和可见性；选择“曲线所属子图”并点击“移动曲线”，即可重新分组。图例可放在顶部、右侧或图内，并可调整列数和字号。

## 时间、事件与局部放大

- **时间范围**：在“X 范围”输入两个数，如 `1.3, 1.7`，数值对应当前显示单位。
- **相对时间**：设置已知事件时刻为零点，并选择 ms 等时间单位，便于比较事件前后的波形。
- **事件标记**：填写事件时刻和名称，将事件线加到对应子图。
- **局部放大**：展开“局部放大图”，选择“新增”，填写局部时间范围及位置、尺寸并应用。
- **数字轨道**：对 0/1 逻辑信号，可选择“数字量分层轨道”显示阶梯状态。

局部图输入时间使用界面当前刻度；通过 MCP 指令指定局部窗口时使用绝对秒值。例如主图以 1.5 s 为零点，局部窗口 1.49–1.51 s 对应相对时间 −10–10 ms。

## 导出图形

在“导出论文图”选择格式并点击“导出当前视图”。点击“一键导出中英文”可分别生成两种语言的图形，随后下载图形 ZIP。

| 格式 | 常用场景 |
|---|---|
| PDF | 论文、报告和打印 |
| SVG | 矢量编辑和网页展示 |
| PNG | 幻灯片、预览和交流 |

按目标期刊设置单栏或双栏画布尺寸，导出后检查最终插入尺寸下的文字大小。

## 工程管理

### 保存与重开

输入工程名称并点击“保存工程”。工程保存在 `.wavelab/projects/<工程名>/`，包含绘图配置 `project.json` 和数据目录 `data/`。下次从左侧“已保存工程”选择并打开。

### 换电脑继续绘图

1. 在旧电脑保存工程。
2. 在新电脑按首页步骤安装工作台。
3. 将整个工程目录复制到新电脑的 `.wavelab/projects/` 下。
4. 启动工作台，从“已保存工程”打开。

每台电脑分别创建 Python 虚拟环境；使用 Codex 时，在新电脑重新配置 MCP 路径并选择编辑目标。同名工程复制前先备份。

### 更新工作台

保存工程并关闭终端中的工作台。Git 安装可执行 `git pull --ff-only`，再重新运行 pip 安装命令和启动命令。有本地代码修改时先处理差异。ZIP 安装可解压新版到新目录，再复制工程目录。

更新后重新启动工作台，使用 Codex 时同时重启 MCP 连接。

## 常见问题

| 现象 | 处理方法 |
|---|---|
| 找不到 py 或 python | 安装 Python 3.11+ 并重开终端，运行 `py -3 --version` 或 `python --version` 检查 |
| Linux 缺少 venv | 安装发行版对应的 Python venv 组件后重新创建环境 |
| PowerShell 提示脚本禁止运行 | 使用首页中直接调用 `.venv` Python 的启动命令 |
| 找不到 app.py | 进入解压后包含 app.py 和 pyproject.toml 的目录 |
| 提示缺少 wavelab 或 streamlit | 用启动时的同一虚拟环境执行 `-m pip install -e .` |
| 安装依赖下载失败 | 检查网络、代理和 pip 软件源后重新安装 |
| 8501 端口被占用 | 改用 `--server.port 8502`，浏览器打开对应端口 |
| 中文显示方框 | 安装中文字体，重启工作台后重新导出 |
| 曲线为空 | 检查目标子图是否已添加通道、曲线是否可见、时间范围内是否有采样 |
| 想继续编辑已导出的图片 | 从已保存工程打开绘图配置，再修改和导出 |
