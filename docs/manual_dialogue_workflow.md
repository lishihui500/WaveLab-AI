# 使用 ChatGPT 协作绘图

在 ChatGPT 中讨论绘图要求，再把最终方案粘贴回工作台，即可预览并应用修改。

## 操作步骤

1. 打开工程，展开“AI 科研绘图助手”中的“其他方式：ChatGPT / API”。
2. 勾选“启用 AI 助手”，选择“ChatGPT 手动协作”。
3. 输入要求，点击“生成 ChatGPT 请求”，将请求内容复制到 ChatGPT。
4. 在同一 ChatGPT 对话中回答问题、补充细节，直到得到最终 JSON 方案。
5. 将最终结果粘贴到“粘贴 ChatGPT 返回结果”，选择对应方案来源，点击“解析并验证方案”。
6. 查看修改摘要与预览，确认后应用。需要保留结果时点击“保存工程”。

例如，可以输入：

> 把六条曲线分成三幅子图，每幅两条。上桥臂使用实线，下桥臂使用虚线，图例放在顶部。

## 补充信息

如果 ChatGPT 询问“第二条曲线指的是哪幅子图”，直接在同一对话回答即可。对话中确认了新的事件时刻或源单位时，将确认内容填入工作台的“后续确认原话”。

讨论期间保持工作台绘图设置不变；若已在本地改图，重新点击“生成 ChatGPT 请求”，用最新内容生成方案。完成一次修改后，下一次请求使用最新工程状态。
