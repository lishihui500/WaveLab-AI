# 多轮澄清与单次最终执行

1. 重启工作台服务并重新打开工程，使新代码生效。启用 AI 助手，选择 ChatGPT 手动协作。
2. 输入完整绘图要求，生成并检查请求，复制到自己的 ChatGPT 对话。
3. 直接在该对话回答澄清或纠正目标。无需导入中间回复、无需重新导出快照。
4. 信息齐全后仅复制最终 JSON 到工作台，解析、检查差异与预览，再确认应用。
5. 若后续确认新增事件秒值或源单位，在“后续确认原话”中填写自己的原话。保持原有 evidence_quote 校验；不能把模型生成的时间当作用户确认。纯样式目标确认无需填写。
6. 澄清期间本地配置发生修改，旧方案会被拒绝，重新生成快照。完成或取消后，下一任务使用新快照。

本说明取代阶段 3C.2 中手动协作允许非冲突合并的历史行为。旧 clarification JSON 仍可解析，但只提示返回原对话回答，不执行动作。

唯一显示名称可用于样式目标定位；重复名称须明确子图和 channel_id。对话确认不改变物理映射。物理语义与单位仍受严格确认和白名单限制。

代码与回归验证覆盖提示词、真实协议导出、本地解析、事务、过期拒绝和多动作完整性；自动测试不代表真实 ChatGPT 多轮生成效果已验收。没有调用任何模型 API。
