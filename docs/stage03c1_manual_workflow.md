# ChatGPT 手动协作使用指南

阶段 3C.1，2026-10-17。本模式不使用 API Key 或 OAuth，WaveLab 不向模型服务发送请求。你在自己的 ChatGPT 对话中使用现有套餐；ChatGPT 本身仍有套餐用量限制。

## 启动与准备

在项目根目录运行 `start_workbench.ps1`，打开 http://127.0.0.1:8501。也可运行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

导入数据或打开完整工程，选择曲线。若要求按 ABC/六桥臂处理，先在“确认物理映射”明确顺序和单位。测试集1顺序已由用户确认；其他数据不能直接套用。使用合成案例可运行 `python scripts/stage03c1_acceptance.py`（请使用项目 .venv Python），从 `reports/stage_03C1/synthetic/workspace/projects/Browser_base/project.json` 打开演示工程。此脚本只做本地验收，不调用 ChatGPT；重复运行会更新该脚本自己的验收产物。

## 步骤 1：生成并复制请求

展开“AI 科研绘图助手”，勾选启用，保留默认“ChatGPT 手动协作”。输入完整的本轮要求，例如：

> 将 A 相上桥臂设为蓝色实线，A 相下桥臂设为红色虚线，故障时刻设置为 1.5 s，横坐标使用相对毫秒，其余配置保持不变。

点击“生成 ChatGPT 请求”。展开“查看即将复制的内容”，检查通道名称、专业标签和本轮要求是否含研究信息。生成只发生在按钮点击时，刷新控件不会自动替换请求。

请求含当前脱敏配置、可操作 ID、已确认单位/角色、16种命令的实际 schema 与参数约束、本轮要求和绑定信息；不含采样数组、源路径、源文件名、工程名、源哈希或认证配置。用户自己写在标签/要求里的研究名称仍会出现，复制前须检查；不要在任何名称或标签中填写凭据。

点击“一键复制请求”，界面显示“已复制请求”。若浏览器拒绝自动复制，会先尝试兼容模式；仍失败时显示“自动复制失败”，选中只读文本框后按 Ctrl+A、Ctrl+C。也可下载请求文本。页面代码区右上角另有 Streamlit 原生复制按钮。

由你主动粘贴到 ChatGPT 对话并发送。WaveLab 不自动打开或控制你的 ChatGPT，不读取聊天记录、Cookie 或 token。

## 步骤 2：导入返回 JSON

要求 ChatGPT 仅返回完整 JSON。外层包含 `request_id`、`revision`、`fingerprint`、`plan`，前三项原样回显；plan 使用原有 Plan schema，含 summary、clarification、actions。完整格式由请求中的 output_schema 自动生成，不需要手工拼装。

在“方案来源”如实选择：脚本构造、Mock、用户从真实 ChatGPT 获取或未核实。该选择是用户声明，程序不能据此证明真实模型成功。

粘贴到“粘贴 ChatGPT 返回结果”，点击“解析并验证方案”。兼容单层完整的 ```json 代码块；不接受代码块外说明、多块拼接、Python代码、重复 JSON 字段、未知字段或超过250000字符的返回。

校验使用生成请求时保存的原始要求，因此事件证据必须来自该要求的明确秒值或已有确认事件。若模型要求澄清，补全自然语言要求，重新生成请求。出错时修正 JSON 或重新问 ChatGPT，当前图形不变；界面显示字段及原因，不显示内部堆栈。

## 步骤 3：核对并应用

校验成功后核对字段原值/新值和候选图。此时当前 FigureSpec、画布和导出内容尚未改变。点击“确认应用协作方案”才提交；取消则保留原图形。确认后 GUI 属性同步，可在画布区域撤销、恢复。

每轮只生成一个当前请求；生成新请求会替换待确认方案。应用和取消后该请求关闭，不能反复导入执行。导入失败会清除之前待应用候选，避免误应用旧的有效方案。

## 连续三轮及过期处理

每轮应用后重新生成请求，附完整最新状态。例如先六桥臂分三子图，再英文轴/中文图例，最后给出故障秒值并设置相对毫秒范围。同一 ChatGPT 对话的旧记忆不能替代最新请求。

生成请求后的独立手动修改可由 3C.2 三方检查合并；同字段不同值、依赖冲突、撤销恢复、重新打开或切换工程须重新生成。返回仍须回显原请求绑定；改版本号或指纹无法绕过本地快照。预览后再改图时，先重新校验并更新候选图，再次确认后提交。只改变文本输入尚不修改图形，但导入使用原生成要求，改要求后也应重新生成。

刷新 Streamlit 控件保留本会话文本及方案；关闭浏览器会话、服务重启后不保证恢复协作请求。完整工程只保存有效绘图配置与数据副本，不保存聊天、粘贴内容、待应用方案或密钥。需要保留请求可主动下载文本；研究请求和本地验收记录不应直接公开。

## 保存、导出及其他模式

确认应用后在侧栏为工程命名并保存。重新打开完整工程检查曲线、坐标和语言；随后“一键导出中英文”生成 PDF/PNG/SVG。相对毫秒范围使用显示单位，例如故障前后20ms填 `[-20,20]`；事件时刻始终使用原始秒值。

“OpenAI API”保留独立付费服务入口，需主动选择并确认元数据外传/费用。手动协作失败不会切换 API。“Mock（测试）”仅返回固定澄清回复，用来检查本地接口，不能作为自然语言绘图证明。手动绘图功能不依赖这些模式。

## 真实模型验收清单

先使用合成工程，按 `examples/stage03c1_test_prompts.md` 的12条任务逐条记录。每条分别保存：原要求/请求、真实 ChatGPT 返回、是否有效方案、是否本地校验通过、是否人工确认执行、最终图像是否符合意图、人工干预次数、失败原因。任何失败均保留；零次真实测试时不计算成功率。

模型耗时由人工记录；Token 若界面未提供则留空。WaveLab 的 local_elapsed_s 仅是解析/校验/试绘耗时，不是模型延迟。下载记录中的 model_calls=0 只代表工作台未调用 API，不能解释为你在 ChatGPT 内没有使用模型。用户来源标记为 user_chatgpt 仍保留 model_generation_verified=false，真实证据需另附对话输出。

研究数据脱敏元数据向 ChatGPT 外传前仍须由用户决定；本地真实数据验收不需要对外发送。将失败的 JSON 与对应请求反馈用于修复即可，不需要任何登录凭据。
